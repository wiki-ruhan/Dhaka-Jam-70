## নতুন: ৭০টি মোড়ের বিশ্লেষণ

**তালিকা:** `junctions.py`-এ (৭টি করিডোর: উত্তর/বিমানবন্দর সড়ক, বনানী–মহাখালী–তেজগাঁও, গুলশান–বাড্ডা–রামপুরা, মিরপুর–গাবতলী–আমিনবাজার, ধানমন্ডি–মোহাম্মদপুর, কেন্দ্রীয় ঢাকা, দক্ষিণ/পুরান ঢাকা)।

**হুবহু অবস্থান:** প্রথম রানের init জবে সিস্টেম OpenStreetMap থেকে প্রতিটি মোড়ের আসল সংযোগস্থল আর প্রতিটি দিকের রাস্তা (নামসহ) বের করে `data/junctions_exact.csv`-এ রাখে (Drive-এর `data` ফোল্ডারেও যায়)। OpenStreetMap না পেলে আনুমানিক অবস্থান থেকে ৮ দিকের সোজা রেখা ব্যবহার হয়।

**প্রতি স্লটে প্রতিটি মোড়ের যা মাপা হয়:**

| কলাম | মানে |
|---|---|
| `score_area` | মোড়ের চারপাশে ৩০০ মিটারের যানজট স্কোর (০–১০০) |
| `max_queue_red_m` | যেকোনো দিকে মোড় পর্যন্ত টানা লাল/গাঢ় লাল জ্যামের দৈর্ঘ্য (মিটার) |
| `max_queue_slow_m` | কমলাসহ ধীরগতির সারির দৈর্ঘ্য |
| `worst_leg` | কোন দিকের রাস্তায় জ্যাম সবচেয়ে লম্বা |
| `severe` | তীব্র জ্যাম কি না (স্কোর ≥ ৫০ অথবা জ্যাম ≥ ৩০০ মিটার) |
| `spill_to` | জ্যাম কোন পাশের মোড় পর্যন্ত পৌঁছে গেছে |
| `legs.csv` | প্রতিটি দিকের রাস্তা আলাদা: মোড়ের দিকে আসা গাড়ির স্কোর ও জ্যামের দৈর্ঘ্য, বেরিয়ে যাওয়া দিকের স্কোর |

**প্রতিদিনের র‍্যাংকিং (`ranking`):** গড় স্কোর (সকাল ৬টা–রাত ১২টা), সর্বোচ্চ স্কোর ও সময়, দিনে কত ঘণ্টা তীব্র জ্যাম, সর্বোচ্চ ও গড় জ্যামের দৈর্ঘ্য, সবচেয়ে আটকানো দিক, সকাল ও বিকেলের পিকের পর স্বাভাবিক হতে কত মিনিট, পাশের মোড়ে ছড়িয়ে পড়ার সংখ্যা।

## ধাপ ২: Apps Script আপডেট (একবার, ৩ মিনিট)

1. script.google.com → আপনার আগের প্রজেক্ট খুলুন।
2. পুরো কোড মুছে নতুন `Code.gs`-এর লেখা পেস্ট করুন। `TOKEN`-এ **আগের মতো একই** গোপন শব্দ দিন। তারপর 💾 Save।
3. **Deploy → Manage deployments** → আগের deployment-এর পাশে ✏️ → **Version: New version** → **Deploy**।
   এভাবে করলে URL একই থাকে, GitHub-এর secret বদলাতে হয় না।
4. অনুমতি চাইলে **Authorize** করুন।
5. পরীক্ষা: Web app URL ব্রাউজারে খুললে লেখা আসবে `Dhaka traffic Drive receiver v5 is running`।

## ধাপ ৩: GitHub-এ ফাইল বদলান

**ব্রাউজারে:** Add file → Upload files দিয়ে এই ৬টি ফাইল আপলোড করুন:
`config.py`, `collector.py`, `runner.py`, `analyze.py`, `dashboard_template.html`, `README_BN.md`

তারপর `.github/workflows/collect.yml` খুলে ✏️ চাপুন, সব মুছে নতুন `collect.yml`-এর লেখা পেস্ট করে Commit করুন।

**পিসিতে git দিয়ে:** zip-এর সব ফাইল (`.github` ফোল্ডারসহ) রিপোতে কপি করে `git add -A && git commit -m "v5" && git push`।

## ধাপ ৬: চালু করুন

1. Actions-এ চলমান রান থাকলে **Cancel workflow** চাপুন।
2. **Dhaka traffic collector → Run workflow** চাপুন।
3. `STUDY_VERSION = 5` হওয়ায় আগের তথ্য নিজে থেকেই `data/old_v4`-এ সরে যাবে, আর নতুন ৩০ দিন শুরু হবে।
4. **init** জবের লগে `--plan`-এর ফল আর প্রথম স্ন্যাপশটের সময় দেখা যাবে।
5. **collect** জবের লগে এমন লাইন আসবে:
   `[20261014-0845] worker 0: tiles 35/35 score=47.3 08:45:07-08:52:31 took=460s image=150MB`
6. Drive → **Dhaka Traffic Snapshots → তারিখ** ফোল্ডারে `…_z18.png` আর একই নামের `.json` আসবে।
